# Number Guessing Game

This is a simple Java Number Guessing Game.

## Description

The game generates a random number between 1 and 100. The player has a maximum of 3 attempts to guess the correct number. The program also handles invalid input and keeps track of the player's score.

## Features

- Generates a random number from 1 to 100
- Allows up to 3 attempts
- Shows whether the guess is too high or too low
- Handles invalid input
- Keeps track of the score

## Technologies Used

- Java
- IntelliJ IDEA

## How to Run

1. Open the project in IntelliJ IDEA.
2. Run the Java program.
3. Enter your guess when asked.
4. Try to guess the number within 3 attempts.
